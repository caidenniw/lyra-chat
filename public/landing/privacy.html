Lyra Mulai Chat

Kebijakan Privasi

Terakhir diperbarui: 17 Juli 2026

1. Informasi yang Kami Kumpulkan

Lyra AI menghormati privasi kamu. Kami hanya mengumpulkan data yang diperlukan untuk menjalankan layanan:

  • Akun (opsional): jika kamu mendaftar, kami menyimpan alamat email untuk autentikasi.
  • Percakapan: riwayat chat disimpan untuk memungkinkan fitur riwayat percakapan. Data ini tidak dibagikan ke pihak ketiga.
  • Data penggunaan: informasi anonim seperti waktu akses dan model yang digunakan, untuk meningkatkan layanan.

2. Cara Kami Menggunakan Data

  • Menjalankan dan memelihara layanan Lyra AI.
  • Menyediakan riwayat percakapan antar sesi (khusus pengguna terdaftar).
  • Meningkatkan kualitas respons AI melalui evaluasi anonim.

3. Penyimpanan Data

Data percakapan disimpan di server Supabase (Eropa/Amerika). Untuk pengguna Guest Mode, data hanya disimpan di memori lokal browser dan akan hilang setelah sesi berakhir atau browser ditutup.

4. Berbagi Data dengan Pihak Ketiga

Lyra menggunakan OpenCode Zen API sebagai penyedia model AI. Saat kamu mengirim pesan, konten dikirim ke server OpenCode untuk diproses. OpenCode memiliki kebijakan zero-retention: data tidak disimpan atau digunakan untuk pelatihan model.

5. Keamanan

Kami menggunakan enkripsi HTTPS untuk semua komunikasi. Autentikasi pengguna ditangani oleh Supabase dengan standar keamanan industri.

6. Hak Kamu

  • Kamu dapat menghapus percakapan kapan saja melalui menu di aplikasi.
  • Kamu dapat meminta penghapusan akun dan seluruh data dengan menghubungi kami.
  • Kamu dapat menggunakan Lyra dalam Guest Mode tanpa memberikan data pribadi.

7. Kontak

Untuk pertanyaan tentang privasi, hubungi: github.com/caidenniw

8. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan diumumkan melalui halaman ini.
